# Save where we are

**Group:** Keep your AI work going · **Kits:** Side project · **For:** Everyone

Replace any [bracketed blanks] with your own details, then paste the prompt into ChatGPT, Claude, Gemini or another AI chat.

```text
Before I close this chat, write a handoff note so I can continue this work in a new chat later.

Include, based only on this conversation:
1. The goal, in one or two sentences.
2. Decisions we made, and why.
3. Where things stand right now: what's done and what's in progress.
4. Important facts, names, numbers or preferences a new chat would need.
5. Open questions, and anything we weren't sure about.
6. The next three steps.

Don't add anything we didn't discuss. Mark guesses like this: (guess: ...). Keep it under 300 words, and format it so I can paste it straight into a new chat, starting with: "Here's where we left off:"
```
